От идеи к первому кадру

Склонируйте репозиторий. Генератор создаст приложение с локальной зависимостью Rusterize. Нужны Rust 1.85+ и Python 3.10+.

git clone https://github.com/USBashka/Rusterize.git
cd Rusterize
cargo run -p rusterize-cli -- new ../hello-rusterize
cd ../hello-rusterize
rustup target add wasm32-unknown-unknown
python scripts/build.py --platform web
